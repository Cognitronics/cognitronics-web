# Cognitronics

**Cognitive systems · Artificial life · AI experiments**

This repository contains the source of [cognitronics.ai](https://cognitronics.ai) –
the home of Cognitronics, an independent project exploring how artificial agents
learn, perceive and develop language.

## Projects

- **NikolAI** – an artificial creature with a neural brain that learns language
  through curiosity and interaction. → [nikolai.cognitronics.ai](https://nikolai.cognitronics.ai)
- **Games** – browser-based experiments. → [cognitronics.ai/games](https://cognitronics.ai/games)

## Tech stack

- Static landing page (HTML/CSS/JS)
- Self-hosted on a VPS with Docker
- Reverse proxy & TLS via Nginx Proxy Manager

## Deployment

```bash
git pull origin main
```
